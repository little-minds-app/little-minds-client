# Shape Matching SFX (original, offline)

**Jira:** LMP-55 visual redesign / preschool SFX follow-up · **PR:** #41

Commercial-safe **procedurally synthesized** PCM WAV cues. No voice packs, no
copyrighted music, no runtime download, no BGM in this phase.

## Tech

- 16-bit PCM mono WAV @ 22.05 kHz
- Generated by `scripts/generate_shape_matching_sfx.py` (deterministic)
- Bundled under `assets/audio/shape_matching/sfx/`

## Cues

| File | Use |
|------|-----|
| `tap_pop.wav` | Choice tap |
| `drag_bounce.wav` | Drag start |
| `correct_chime.wav` | Correct match (two-tone) |
| `soft_clap.wav` | Bunny paw clap (synced after chime) |
| `wrong_soft.wav` | Friendly wrong |
| `complete_jingle.wav` | Session completion (richer than mid-match) |
| `twinkle.wav` | Optional celebrate sparkle |

## Provenance

- Synthesis only (sine harmonics + deterministic noise). No third-party samples.
- Regenerating: `python3 scripts/generate_shape_matching_sfx.py`
